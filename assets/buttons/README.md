# assets/buttons/

Placeholder pixel-style nav buttons for the arcade menu at the top of the
profile README. Redraw these in Aseprite and overwrite in place, exact
same filenames so the README doesn't need edits:

| File | Pixel size | Label |
|---|---|---|
| `nav-projects.svg` | 168x40 | PROJECTS |
| `nav-skills.svg` | 168x40 | SKILLS |
| `nav-stats.svg` | 168x40 | STATS |
| `nav-contact.svg` | 168x40 | CONTACT |
| `nav-play.svg` | 188x40 | PLAY MY GAMES |

Export settings:
- Export as PNG (or keep as hand-drawn SVG if you prefer vector, either
  renders fine on GitHub) at the pixel size above, no upscaling/resampling.
- Transparent background so it reads on both GitHub light and dark theme.
- If you export PNG instead of SVG, update the five `<img src="...">` paths
  in `README.md`'s `<!-- SECTION: arcade-menu -->` block to point at the
  new `.png` filenames.

Current placeholders are flat-color chunky-border SVG rectangles with cut
pixel corners, generated by hand (no script) since these are one-off
static assets, not data-driven.
